# KIRA Coach — Plataforma de coaching y bienestar

Aplicación web KIRA Coach, desarrollada por **SAFENESS.INC**.

## Desarrollo local

Requisitos: Node.js 20+.

1. Instala dependencias: `npm install`
2. Configura las variables de entorno localmente en `.env.local` (no subir secretos al repositorio).
3. Ejecuta `npm run dev`.
4. Genera la compilación: `npm run build`.

## Variables de entorno

Consulta `.env.example`. Nunca compartas ni commits claves de Gemini, Stripe, Firebase Admin u otros servicios.

## Centro legal y privacidad

KIRA Coach incluye documentos públicos en `/legal/:document`:
- `/legal/privacy`: aviso y política de privacidad.
- `/legal/cookies`: política y preferencias de cookies.
- `/legal/terms`: términos y condiciones.
- `/legal/copyright`: propiedad intelectual y derechos de autor.
- `/legal/data-rights`: ejercicio de derechos de titulares.
- `/legal/moderation`: reglas de comunidad y moderación.
- `/legal/retention`: conservación, seguridad e incidentes.
- `/legal/b2b`: anexo de tratamiento para clientes empresariales.

**Estado:** borradores técnicos sujetos a revisión jurídica y a completar la identificación legal del controlador, canal de privacidad, inventario real de cookies/proveedores, bases legales por operación, retención y transferencias internacionales. No constituyen certificación de cumplimiento.

El aviso de cookies registra las preferencias en el navegador y mantiene desactivadas por defecto las categorías opcionales. No se ha habilitado ninguna herramienta de analítica o publicidad mediante este cambio.
